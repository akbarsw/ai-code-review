# CodeLens AI — AI-Powered Code Review

An intelligent code review tool that detects security vulnerabilities, performance issues, and bad practices instantly — powered by Xiaomi MiMo AI.

🔗 **Live Demo:** https://freeoak.zo.space/code-review

## Features

- 🔐 **Security Scanner** — OWASP Top 10 vulnerabilities (SQL injection, XSS, hardcoded secrets)
- ⚡ **Performance Analyzer** — O(n²) complexity, memory issues, inefficient patterns
- 🎯 **Quality Grading** — A–F score with detailed metrics breakdown
- 🔧 **Auto Fix** — AI-generated fixed version of your code
- 💬 **AI Chat** — Ask follow-up questions about the review
- 🌐 **Multi-language** — Python, JavaScript, TypeScript, Java, Go, Rust, PHP, C++

## Tech Stack

- React + TypeScript
- Tailwind CSS
- Vite
- Lucide React icons
- Powered by Xiaomi MiMo API

## Getting Started

```bash
npm install
npm run dev
```
